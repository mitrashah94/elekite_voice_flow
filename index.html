How It Works

Three steps to freedom
from your keyboard

VoiceFlow runs as a lightweight background process, always listening for your hotkey.

1

Hold your hotkey

Press and hold Option (⌥) — or your configured hotkey — in any app. VoiceFlow starts recording from your microphone instantly. A subtle sound confirms recording has started.

2

Speak naturally

Talk at your normal pace. Say "um" and "like" all you want — the AI will clean it up. Whisper handles accents, background noise, and even whispering remarkably well.

3

Release — text appears

Let go of the hotkey. In ~2 seconds, your transcribed, cleaned-up text is pasted right where your cursor is. No switching apps, no copy-paste, no editing needed.

Installation

Up and running in
under 2 minutes

Terminal 
# 1. Clone the project
git clone https://github.com/your-repo/voiceflow.git
cd voiceflow

# 2. Install dependencies
pip install -r requirements.txt

# 3. Run the setup wizard (configures API key, hotkey, etc.)
python3 setup.py

# 4. Start VoiceFlow!
python3 voiceflow.py

Prerequisites: Python 3.10+, macOS 12+, an OpenAI API key, and Homebrew (for PortAudio).

Configuration

Fully customizable

Edit ~/.voiceflow/config.json or use the built-in Settings GUI.

Setting Default Description
hotkey"option"Trigger key — option, ctrl, cmd_r, caps_lock, fn, shift
mode"hold"hold = hold to record, toggle = press to start/stop
ai_cleanuptruePost-process with GPT to clean filler words & fix grammar
cleanup_model"gpt-4o-mini"GPT model for cleanup — gpt-4o-mini, gpt-4o, gpt-3.5-turbo
language""Language code (empty = auto). Examples: en, es, ja, zh
auto_pastetruePaste transcription at cursor position automatically
sound_feedbacktruePlay macOS system sounds on start/stop
save_recordingsfalseKeep WAV files in ~/.voiceflow/recordings/
custom_prompt""Extra instructions for AI cleanup step
